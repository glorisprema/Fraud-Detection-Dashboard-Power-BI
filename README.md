# Fraud Detection Dashboard - Power BI

## Overview
Fraud Detection Dashboard built in Power BI to monitor high-risk transactions across Hamilton & Toronto branches. Built to help bank fraud team reduce losses.

**KPIs:**
- 26K Fraud Cases
- $15.00M Total Fraud Amount
- $2M Online Withdrawal Fraud
- $4.72M Q-Rule Fraud Amount

## Tools Used
- Power BI Desktop
- DAX Measures
- Power Query
- Fraud Rule Logic (Q-Rule)

## Key Insights
- Total Fraud Amount $15M | Potential Savings $2M | Q-Rule Impact $3.3M (3684 cases)
- Hamilton Downtown has highest fraud by branch
- Online channel = 40.1% of fraud
- Q-Rule flags high-risk online transactions for investigation
